# Virtual-Pet-Simulator-OOP-Project-
A C++ Object-Oriented Programming Console-based application project that simulates a virtual pet system with Dog, Cat, and Rabbit classes. The project demonstrates core OOP concepts including inheritance, polymorphism, encapsulation, constructors, virtual functions, and dynamic memory management.

Project Overview

Virtual Pet Simulator is an interactive console application where the user can adopt a virtual pet and take care of it by feeding, playing with, and putting the pet to sleep.

The simulator includes three types of pets:

- Dog
- Cat
- Rabbit

Each pet has its own sound and unique behavior, demonstrating the use of **inheritance and polymorphism** in C++.

Features:

- Adopt a virtual pet
- Choose between Dog, Cat, and Rabbit
- Give the pet a custom name
- Feed the pet
- Play with the pet
- Put the pet to sleep
- Check pet status
- Health, hunger, happiness, and energy management
- Mood system
- Pet status/progress display
- Passive stat changes after actions
- Game-over condition when the pet's health reaches zero
- Different sounds and unique actions for each pet

## How to Run

1. Download or clone this repository.
2. Open `main.cpp` in a C++ IDE such as Code::Blocks, Dev-C++, or Visual Studio.
3. Compile and run the program.
4. Enter the owner's name.
5. Choose a pet and give it a name.
6. Interact with your virtual pet using the menu options.
